
# React Forms Lab

## Тема
Робота з формами: керовані та некеровані компоненти.

## Мета роботи
Навчитися працювати з формами у React,
використовувати useState, useRef,
об'єкт стану та валідацію даних.

## Використані технології
- React
- JavaScript
- Vite
- Visual Studio Code

## Виконані завдання

### Завдання 1. Керована форма
Створено форму реєстрації з полями імені,
email та пароля через useState.

### Завдання 2. Некерована форма
Реалізовано отримання даних із полів
через useRef із виведенням у консоль.

### Завдання 3. Багатопольова форма
Створено форму профілю з одним об'єктом
стану для імені, прізвища та дати народження.

### Завдання 4. Валідація
Додано перевірку обов'язкових полів,
коректності email та повідомлення про помилки.

## Запуск проєкту

    npm install
    npm run dev

## Результат
Усі чотири завдання виконано.
Роботу форм перевірено у браузері.
Проєкт успішно зібрано командою npm run build.
